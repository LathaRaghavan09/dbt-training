### SHIPMODE - Definition
The `SHIPMODE` column describes the type of shipping method used for order delivery.

#### 🚚 Shipping Modes and Descriptions:
- **Second Class:** Orders are shipped via Second Class with Courier.
- **Standard Class:** Orders are shipped via Standard Class with Courier.
- **First Class:** Orders are shipped via First Class with Courier.
- **Same Day:** Orders are shipped via Same Day Class with Courier.
